Every torch.compile commit that landed between 2026-09-27 and 2026-10-04, including the ones the [issue]({{< relref "/posts/2026-10-04-this-week-in-torch-compile" >}}) only counted.

## Dynamo commits
- Dynamo now raises the same TypeError as eager when a traced __init__ returns a non-None value, instead of silently succeeding. ([#198604](https://github.com/pytorch/pytorch/pull/198604), @hknsahin97-coder)
- Dynamo now preserves the original exceptions and messages from constant-folded Python operations, fixing empty messages and internal crashes versus eager. ([#198590](https://github.com/pytorch/pytorch/pull/198590), @hknsahin97-coder)
- Dynamo now draws from the live random.Random object at runtime instead of baking in trace-time values, fixing stale random numbers on cache hits. ([#196921](https://github.com/pytorch/pytorch/pull/196921), @JaynouOliver)
- Fixes Dynamo passing random float draws as float32 instead of float64, which made Inductor CPU kernels return garbage like -9e34. ([#199075](https://github.com/pytorch/pytorch/pull/199075), @Sahil170595)
- AOTAutograd cache now accepts graphs with inference_mode regions and torch._refs.tensor nodes, which previously bypassed caching entirely. ([#191409](https://github.com/pytorch/pytorch/pull/191409), @aorenste)
- Dynamo can now constant-fold bytes() calls and correctly propagates expected exceptions from constant-like objects such as regex patterns. ([#197499](https://github.com/pytorch/pytorch/pull/197499), @VenkataSriSaiSuryaMandava)
- Dynamo can now trace calls to classmethod() and staticmethod() inside compiled regions instead of graph breaking. ([#197781](https://github.com/pytorch/pytorch/pull/197781), @KarhouTam)
- Fixes torch.compile used as a class decorator crashing under caching_precompile, as hit by flash-linear-attention. ([#191977](https://github.com/pytorch/pytorch/pull/191977), @cjolivier01)
- Dynamo now constant-folds __name__, __module__ and similar metadata on torch builtin functions, so checks like func.__name__.endswith('_') no longer graph break. ([#196049](https://github.com/pytorch/pytorch/pull/196049), @ezyang)
- Dynamo now raises a proper AttributeError for missing attributes on opaque objects, making hasattr and getattr-with-default traceable. ([#196050](https://github.com/pytorch/pytorch/pull/196050), @ezyang)
- Dynamo can now trace custom exception classes whose __init__ calls super().__init__(msg) instead of graph breaking. ([#196051](https://github.com/pytorch/pytorch/pull/196051), @ezyang)
- Disables Dynamo's cache-entry reordering on free-threaded Python builds, avoiding a race that made threads repeatedly recompile cached functions. ([#199210](https://github.com/pytorch/pytorch/pull/199210), @alexmalyshev)
- Dynamo now raises AttributeError when getattr is called for a missing attribute on a builtin type, so try/except and hasattr branches behave like eager. ([#198330](https://github.com/pytorch/pytorch/pull/198330), @VenkataSriSaiSuryaMandava)
- Makes Dynamo's per-region eval-frame flags thread-local, fixing cross-thread interference when multiple threads call compiled functions. ([#196637](https://github.com/pytorch/pytorch/pull/196637), @alexmalyshev)
- Dynamo no longer leaves a reference cycle between observed exceptions and their tracebacks, which kept user frames and locals alive until garbage collection. ([#197567](https://github.com/pytorch/pytorch/pull/197567), @aorenste)
- Adds the first Dynamo model for bytearray with construction and read-only operations, so basic bytearray use no longer graph breaks. ([#192205](https://github.com/pytorch/pytorch/pull/192205), @krastogi-in)
- Fixes AOTAutograd event versioning across stream waits that produced an incorrect graph for multi-stream code. ([#193410](https://github.com/pytorch/pytorch/pull/193410), @kiya00)
- Stream handling under compile_on_one_rank is now rank-portable, so artifacts compiled on one rank can be reused on another without recompiling. ([#196940](https://github.com/pytorch/pytorch/pull/196940), @aorenste)
- Graph break messages now show caret markers pointing at the exact unsupported call, consistently across Python versions. ([#185466](https://github.com/pytorch/pytorch/pull/185466), @jansel)
- The graph break on nn.RNN, GRU and LSTM now happens at the call instead of the attribute load, so code after the RNN is still compiled. ([#186614](https://github.com/pytorch/pytorch/pull/186614), @jansel)
- Fixes unguardable guards for NestedTensor keepdim reductions by evaluating determinate SingletonInt expressions statically. ([#184628](https://github.com/pytorch/pytorch/pull/184628), @jansel)
- Fixes NumPy ndarray operators failing under a default device context in compiled code. ([#185462](https://github.com/pytorch/pytorch/pull/185462), @jansel)
- Dynamo now supports contextlib.closing and preserves mutations to captured lists made by methods of locally defined classes. ([#197830](https://github.com/pytorch/pytorch/pull/197830), @tsho)
- Dynamo now correctly deletes the exception variable after an 'except X as e' block, raising UnboundLocalError on later reads like eager. ([#198380](https://github.com/pytorch/pytorch/pull/198380), @yueyang-yin)
- Improves the error message for legacy torch.distributed collectives called with async_op=True under Dynamo, pointing to async_op=False or functional collectives. ([#195691](https://github.com/pytorch/pytorch/pull/195691), @bhushanasati25)
- Restores optimizers' capturable parameter to its original value after Dynamo forces it on for compilation. ([#184704](https://github.com/pytorch/pytorch/pull/184704), @krastogi-in)
- Adds PrecompileSession and precompile_capture, a caller-driven way to record all compiled variants of a function into a precompile package. ([#198137](https://github.com/pytorch/pytorch/pull/198137), @bobrenjc93)
- Fixes deque.remove always raising under torch.compile even when the element is present. ([#198716](https://github.com/pytorch/pytorch/pull/198716), @jansel)
- Dynamo can now track attribute mutations on Tensors inside tuple/list outputs, such as results of torch.split, instead of graph breaking. ([#198514](https://github.com/pytorch/pytorch/pull/198514), @williamwen42)
- Dynamo can now trace types.DynamicClassAttribute objects created inside a compiled class body instead of graph breaking. ([#199260](https://github.com/pytorch/pytorch/pull/199260), @kvnloo)
- Dynamo can now trace bytearray.hex() and bytearray.decode(). ([#199252](https://github.com/pytorch/pytorch/pull/199252), @kvnloo)
- Dynamo can now trace math.sumprod with non-constant arguments instead of graph breaking. ([#198685](https://github.com/pytorch/pytorch/pull/198685), @jayzuccarelli)
- Proxy tensor tracing now prunes unused view ops from generated graphs unless they bind unbacked symbols. ([#198515](https://github.com/pytorch/pytorch/pull/198515), @ezyang)
- Extends the layer-norm weight/bias dtype check in the decomposition from CUDA to XPU so it matches eager. ([#198647](https://github.com/pytorch/pytorch/pull/198647), @pbielak)
- Dynamo's repr of self-referential UserList and UserDict now matches CPython. ([#198512](https://github.com/pytorch/pytorch/pull/198512), @weicheng-hsu)
- Dynamo now traces truth-testing of property.__isabstractmethod__ so exceptions raised there are handled instead of crashing. ([#198726](https://github.com/pytorch/pytorch/pull/198726), @tsho)
- Avoids inspect.getattr_static when wrapping a module in OptimizedModule, which removes a spurious lru_cache warning under compiled autograd. ([#197191](https://github.com/pytorch/pytorch/pull/197191), @aorenste)
- Internal Dynamo refactor that removes the _base_vt composition approach for user-defined subclasses of builtin containers, fixing identity edge cases. ([#193679](https://github.com/pytorch/pytorch/pull/193679), @guilhermeleobas)
- Dynamo can now apply len, str, bool, min and max to lazy constants. ([#191145](https://github.com/pytorch/pytorch/pull/191145), @guan404ming)
- Dynamo can now trace iter() on list_reverseiterator objects returned by reversed(list). ([#197454](https://github.com/pytorch/pytorch/pull/197454), @VimalN2005)

- Fixes a Dynamo crash when formatting observed exceptions whose arguments are raw ints, such as UnicodeEncodeError. ([#198153](https://github.com/pytorch/pytorch/pull/198153), @shoaib2000857)
- The multi-graph precompile capture config now always lowers the backward eagerly so inference captures made with grad enabled can be saved. ([#198215](https://github.com/pytorch/pytorch/pull/198215), @bobrenjc93)

- Test refactor that makes test_bad_lowering run on non-CUDA accelerators. ([#198358](https://github.com/pytorch/pytorch/pull/198358), @gavinwang269)
- Skips two aot_compile pickler tests that segfault on Meta's Python 3.14 runtime. ([#199531](https://github.com/pytorch/pytorch/pull/199531), @itamaro)
