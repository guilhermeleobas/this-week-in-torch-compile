## Dynamo commits
- Fixes Dynamo's itertools.cycle polyfill so a stateful iterable is iterated only once, matching CPython and eager results. ([#201608](https://github.com/pytorch/pytorch/pull/201608), @mottopanikeiku)

- Optimizes the backward of mean by dividing before expanding the gradient, avoiding an input-sized buffer and returning a stride-0 expanded gradient like sum does. ([#202976](https://github.com/pytorch/pytorch/pull/202976), @matthewdcong)
- Dynamo now guards the code object of inlined bound methods, so replacing a method's __code__ or rebinding it after compilation no longer runs a stale graph. ([#198124](https://github.com/pytorch/pytorch/pull/198124), @RyanL2)

- Dynamo can now trace bytearray.splitlines, partition and rpartition with constant arguments instead of graph breaking. ([#201350](https://github.com/pytorch/pytorch/pull/201350), @Sanskaaar1)

- Dynamo models wrapper objects such as functools.lru_cache wrappers on their real type, fixing attribute reads and isinstance checks. ([#202286](https://github.com/pytorch/pytorch/pull/202286), @guilhermeleobas)
- Dynamo no longer errors on recording an event after an input mutation unless the event created during tracing actually escapes the compiled region. ([#195573](https://github.com/pytorch/pytorch/pull/195573), @kshitij12345)
- Torch.export now records fake values for vmap and jvp calls and keeps those calls through dead code elimination, fixing pass failures on exported vmap/jvp programs. ([#202929](https://github.com/pytorch/pytorch/pull/202929), @shoumikhin)
- Dynamo no longer emits spurious warnings when falling back to constant access for properties with opaque C getters. ([#203206](https://github.com/pytorch/pytorch/pull/203206), @williamwen42)
- Fixes pytree type-name bookkeeping so deregistering or re-registering several types without a serialized name no longer raises KeyError. ([#202974](https://github.com/pytorch/pytorch/pull/202974), @shoumikhin)
- Dynamo can now trace bytearray.find and bytearray.rfind with constant arguments. ([#199685](https://github.com/pytorch/pytorch/pull/199685), @Bala-Mosay)

- Dynamo exposes the methods, getsets and members of constant types, so unbound calls like int.bit_length(255) no longer graph break. ([#202839](https://github.com/pytorch/pytorch/pull/202839), @guilhermeleobas)
- Dynamo now implements CPython's default object comparison for all variable trackers, so ==/!= on objects like super objects or random.Random no longer graph break. ([#199999](https://github.com/pytorch/pytorch/pull/199999), @guilhermeleobas)
- Dynamo can now trace bytearray.replace and bytearray.translate with constant arguments. ([#201966](https://github.com/pytorch/pytorch/pull/201966), @losewayy)
- Fixes Dynamo's reduce_ex polyfill dropping list and dict items, so copying list or dict subclass instances now repopulates their contents. ([#198857](https://github.com/pytorch/pytorch/pull/198857), @nitinjaiswalnj2001)
