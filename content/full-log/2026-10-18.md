Every torch.compile commit that landed between 2026-10-11 and 2026-10-18, including the ones the [issue]({{< relref "/posts/2026-10-18-this-week-in-torch-compile" >}}) only counted.

## Dynamo commits
- Adds a public torch.distributed.functional_collectives module and documentation for the functional collective ops used by DTensor, FSDP2 and torch.compile, previously only available via a private module. ([#200479](https://github.com/pytorch/pytorch/pull/200479), @d4l3k)
- Dynamo now graph breaks on in-place view ops applied to a no-op alias of a graph input (e.g. x.contiguous().unsqueeze_()), fixing a guard-creation IndexError. ([#198103](https://github.com/pytorch/pytorch/pull/198103), @wwoosshh)
- Fixes deserialized training graphs (precompile, packages) packing saved tensors twice when saved-tensor hooks were inlined at compile time. ([#200551](https://github.com/pytorch/pytorch/pull/200551), @bobrenjc93)
- Fixes bool() on a torch.compile'd module raising TypeError when the original module has no __len__; it now falls back to the original module's truthiness. ([#196323](https://github.com/pytorch/pytorch/pull/196323), @CYQFWang)
- Dynamo now supports ctx.set_output_grad_dtype in autograd.Function instead of failing on a missing FunctionCtx attribute. ([#200311](https://github.com/pytorch/pytorch/pull/200311), @pianpwk)
- Dynamo no longer constant-folds three-argument type() calls, which reused one class across calls; such frames now run eagerly (and error under fullgraph). ([#199605](https://github.com/pytorch/pytorch/pull/199605), @williamwen42)
- Dynamo now guards that an instance __dict__ entry doesn't shadow a registered nn.Module attribute, fixing stale compiled graphs after object.__setattr__ on a module. ([#199212](https://github.com/pytorch/pytorch/pull/199212), @aperson30)
- Precompile can now save captures where a graph break happens inside a called function (such as a child module's forward) by writing them as installed-mode artifacts. ([#198523](https://github.com/pytorch/pytorch/pull/198523), @bobrenjc93)
- Dynamo no longer silently drops maxlen when replaying mutations on deque inputs, so bounded deques behave like eager. ([#200528](https://github.com/pytorch/pytorch/pull/200528), @XuehaiPan)
- Dynamo can now trace bytearray.append() and extend() instead of graph breaking. ([#199675](https://github.com/pytorch/pytorch/pull/199675), @jayzuccarelli)
- Precompiled artifacts that inline functions with module-less globals (such as namedtuple constructors) can now be served in a fresh process instead of always missing guards. ([#200823](https://github.com/pytorch/pytorch/pull/200823), @bobrenjc93)
- Fixes precompile capture and package install failing with a 'bundler already active' error when the bundled autotune remote cache is enabled. ([#200832](https://github.com/pytorch/pytorch/pull/200832), @bobrenjc93)
- Precompile now serves frames that compile to no graph and lose a guard by running them eagerly, instead of refusing the capture. ([#200836](https://github.com/pytorch/pytorch/pull/200836), @bobrenjc93)
- Torch.autograd.grad and backward now accept any Mapping (including OrderedDict, which returns an OrderedDict) as inputs. ([#178500](https://github.com/pytorch/pytorch/pull/178500), @XuehaiPan)
- Dynamo now drops references to tracing state before running gc after compile, so it no longer pins large activations (26 GiB in one case) when automatic gc is disabled. ([#200970](https://github.com/pytorch/pytorch/pull/200970), @Microve)
- Fixes the FX graph cache failing to load graphs with a nested invoke_subgraph, which previously recompiled every time. ([#192842](https://github.com/pytorch/pytorch/pull/192842), @aorenste)
- With nested graph breaks enabled, skipped functions now keep correct attribute semantics so AttributeError no longer leaks out of inspect.signature. ([#199600](https://github.com/pytorch/pytorch/pull/199600), @williamwen42)
- Fixes an IndexError after a nested graph break under compiled autograd by preserving aliases of stolen input tensors. ([#200437](https://github.com/pytorch/pytorch/pull/200437), @williamwen42)
- Fake tensor conversion now keeps a tensor's backend metadata (PrivateUse1), which was previously dropped under torch.compile. ([#186324](https://github.com/pytorch/pytorch/pull/186324), @voidbag)
- Fixes Dynamo crashing on synchronize(None) for cpu/cuda/xpu/mps/mtia/accelerator by treating an explicit None as the current device, as eager does. ([#200556](https://github.com/pytorch/pytorch/pull/200556), @jinyouzhi)
- AOTAutograd cache keys now include annotation values, fixing stale cache hits across fx.traceback.annotate values, plus other annotate edge cases. ([#199954](https://github.com/pytorch/pytorch/pull/199954), @soulitzer)
- Disables nested graph breaks in iterator operations that run in Dynamo host Python, fixing corrupted iterator state. ([#199218](https://github.com/pytorch/pytorch/pull/199218), @williamwen42)
- Dynamo now traces consume_prefix_in_state_dict_if_present as a user function so its in-place dict mutations are replayed correctly. ([#199599](https://github.com/pytorch/pytorch/pull/199599), @williamwen42)
- A graph break inside a TorchScript ScriptFunction call now unwinds to the real ScriptFunction, preserving TorchScript semantics such as is_scripting(). ([#199603](https://github.com/pytorch/pytorch/pull/199603), @williamwen42)
- Dynamo now detects writable output arguments not named 'out' (e.g. values, indices, out0) so fake-tensor propagation doesn't corrupt shape guards. ([#199342](https://github.com/pytorch/pytorch/pull/199342), @williamwen42)
- Dynamo now calls bound builtin methods through their original descriptor instead of re-resolving the name on the receiver's type, so subclass overrides no longer change the call. ([#199881](https://github.com/pytorch/pytorch/pull/199881), @guilhermeleobas)
- Installed precompile artifacts now refuse recompiles with their own callback instead of toggling the process-global fail_on_recompile stance, which broke concurrent torch.compile calls in other threads. ([#198557](https://github.com/pytorch/pytorch/pull/198557), @bobrenjc93)
- Precompile now compares saved-tensors-hook guards by content after serialization. ([#198786](https://github.com/pytorch/pytorch/pull/198786), @bobrenjc93)
- Precompile no longer treats a cache miss in a disable(recursive=False) frame as a recompile. ([#198787](https://github.com/pytorch/pytorch/pull/198787), @bobrenjc93)
- Precompile can now serialize guards on custom_op handles by their registered name. ([#199152](https://github.com/pytorch/pytorch/pull/199152), @bobrenjc93)
- Precompile now resolves exec-generated code such as dataclass __init__ through the frame's globals module. ([#198778](https://github.com/pytorch/pytorch/pull/198778), @bobrenjc93)
- Precompile keeps identity guards on objects that unpickle by reference. ([#198779](https://github.com/pytorch/pytorch/pull/198779), @bobrenjc93)
- Precompile prunes unguarded attributes of guarded user objects when pickling guard state. ([#198780](https://github.com/pytorch/pytorch/pull/198780), @bobrenjc93)

- Precompile carries guarded Python attributes of tensors through guard state. ([#198782](https://github.com/pytorch/pytorch/pull/198782), @bobrenjc93)

## Inductor commits
- Fixes flex attention decoding so the safe-boundary setting is computed from each config's own BLOCK_M, which previously failed when BLOCK_M was pinned to a non-default value. ([#201328](https://github.com/pytorch/pytorch/pull/201328), @felipemello1)
- CUDA graphs now preallocate their RNG state before capture, fixing a cudaErrorCapturedEvent failure when RNG is lazily initialized during capture. ([#193993](https://github.com/pytorch/pytorch/pull/193993), @eee4017)
- Adds a precompile.no_compilation() policy that raises if any graph or Triton compilation, autotuning or JIT build happens while serving a precompiled artifact. ([#198942](https://github.com/pytorch/pytorch/pull/198942), @bobrenjc93)
- Fixes MPSInductor truncating int64 constants to 32-bit, which miscompiled expressions like where(x < 0, 0, x) (seen with Gemma-4). ([#201060](https://github.com/pytorch/pytorch/pull/201060), @Isalia20)
- Precompile captures now freeze Triton kernels with their selected config and a static launcher into the cache, so serving needs no triton.compile or autotuning. ([#198954](https://github.com/pytorch/pytorch/pull/198954), @bobrenjc93)
- Prunes flex attention configs with large blocks for head_dim above 256 on Blackwell (sm_10x), avoiding a known Triton miscompile that caused memory faults. ([#200725](https://github.com/pytorch/pytorch/pull/200725), @drisspg)
- Relands fusion of pointwise producers into template epilogue inputs such as the addmm/baddbmm bias, so a computed bias no longer needs its own kernel and buffer. ([#200591](https://github.com/pytorch/pytorch/pull/200591), @laithsakka)
- Fixes compiled conv2d backward returning channels-last grad_input strides under layout optimization, so strides now match eager. ([#198120](https://github.com/pytorch/pytorch/pull/198120), @MBUYt0n)
- Fixes a CUDA misaligned-address error in scaled dot product attention by skipping flash and cuDNN when q/k/v row starts aren't 16-byte aligned. ([#199304](https://github.com/pytorch/pytorch/pull/199304), @liangel-02)
- MPSInductor now computes in float32 after casts to fp16/bf16, fixing a bf16 compile failure and wrong fp16 results such as log1p returning 0 for small inputs. ([#200559](https://github.com/pytorch/pytorch/pull/200559), @Isalia20)
- Functional collectives now accept collective configs, preserved through autograd, export, LocalTensor and Inductor, and included in bucketing and runtime-estimate caches. ([#199224](https://github.com/pytorch/pytorch/pull/199224), @d4l3k)
- Fixes wrong results with triton.enable_pdl (programmatic dependent launch) when a kernel read a buffer before a preceding store-only kernel had finished. ([#199445](https://github.com/pytorch/pytorch/pull/199445), @1fanwang)
- Fixed a bug where, under CUDA graphs (reduce-overhead), a compiled function returning a CPU-constructed tensor returned a CUDA tensor instead. ([#199007](https://github.com/pytorch/pytorch/pull/199007), @oonyshch)
- Inductor now runs very large short reductions in their own kernel instead of inside combo kernels, avoiding a bad shared config that made one such kernel 6x slower. ([#200700](https://github.com/pytorch/pytorch/pull/200700), @desertfire)
- FlexGEMM now allows output transforms to be combined with captured tensors, auxiliary outputs and variable-length-M reductions, and fixes a bug where stored group reductions ignored the per-expert row offset. ([#201127](https://github.com/pytorch/pytorch/pull/201127), @drisspg)

- CuteDSL epilogues now turn division by a constant into a reciprocal multiply under fast math, giving large speedups in FlexGEMM epilogues. ([#201085](https://github.com/pytorch/pytorch/pull/201085), @drisspg)
