Every torch.compile commit that landed between 2026-09-13 and 2026-09-20, including the ones the [issue]({{< relref "/posts/2026-09-20-this-week-in-torch-compile" >}}) only counted.

## Dynamo commits
- Fixed guard-state serialization so shared singletons like `torch.float32` and `Ellipsis` are never pruned, which previously produced artifacts that failed to load with a dtype error. ([#197749](https://github.com/pytorch/pytorch/pull/197749), @bobrenjc93)
- Loading an AOT-compiled module whose forward is wrapped by `torch.compile` or `disable` now resolves the right guard scope instead of failing with a KeyError on user globals. ([#196908](https://github.com/pytorch/pytorch/pull/196908), @bobrenjc93)
- Fixed AOT-compiled artifacts serving the load-time value of a guarded global; the global is now re-read before every call, avoiding silently wrong numerics when it is rebound. ([#196897](https://github.com/pytorch/pytorch/pull/196897), @bobrenjc93)
- Function artifacts loaded with `f_globals` now also re-read guarded globals per call, closing the same silent wrong-numerics case on the function load path. ([#197218](https://github.com/pytorch/pytorch/pull/197218), @bobrenjc93)
- Fixed `torch.Tensor(torch.Size(...))` under Dynamo, which was treated as data and produced a tensor of the wrong shape instead of the requested size. ([#196717](https://github.com/pytorch/pytorch/pull/196717), @karatarassul4-max)
- Dynamo now models `OrderedSet` separately from `set`, preserving insertion order across the compile boundary in reconstruction and `repr`. ([#196167](https://github.com/pytorch/pytorch/pull/196167), @yashb98)
- Fixed `random.seed()` not affecting scalar draws like `random.random()` on the first compile, which gave results differing from eager. ([#197221](https://github.com/pytorch/pytorch/pull/197221), @aperson30)
- FlexGEMM now raises on backward under torch.compile instead of silently producing no gradients, and guards kernel_options keys. ([#196320](https://github.com/pytorch/pytorch/pull/196320), @drisspg)
- Loading an AOT-compiled module now resolves its guard scope from `model.forward`'s live globals, fixing both stale and missing global guards. ([#196818](https://github.com/pytorch/pytorch/pull/196818), @bobrenjc93)
- Fixed a Dynamo bug where compiling code after loading a previously saved compiled package could crash due to a global variable name collision, by minting names guaranteed unique to the target module. ([#196822](https://github.com/pytorch/pytorch/pull/196822), @bobrenjc93)
- Nested compile regions now support `max_autotune` as a region-local Inductor option, with supported keys documented. ([#195865](https://github.com/pytorch/pytorch/pull/195865), @desertfire)
- Dynamo can now trace `delattr` on special exception attributes like `args` and `__traceback__`, raising the same errors CPython does instead of reporting it as unsupported. ([#196722](https://github.com/pytorch/pytorch/pull/196722), @jacobhorne-jth)
- Concrete distributed backends such as NCCL, Gloo and FakeProcessGroup are now pruned from guard state like process groups, fixing a pickling failure. ([#197750](https://github.com/pytorch/pytorch/pull/197750), @bobrenjc93)
- Precompile packages now refuse DDPOptimizer frames with an explicit error naming the `optimize_ddp` settings that do work. ([#197721](https://github.com/pytorch/pytorch/pull/197721), @bobrenjc93)
- Dynamo's `operator.length_hint` now matches CPython for NotImplemented, invalid, negative and oversized hints, fixing silent eager vs compiled differences. ([#196901](https://github.com/pytorch/pytorch/pull/196901), @KarhouTam)
- Dynamo now checks that an import result is a module before binding an alias, fixing a crash when a non-module sits in `sys.modules`. ([#197745](https://github.com/pytorch/pytorch/pull/197745), @bobrenjc93)
- Dynamo can now trace `math.gcd` and `math.lcm` on objects implementing `__index__`. ([#197222](https://github.com/pytorch/pytorch/pull/197222), @KarhouTam)
- Dynamo now graph-breaks instead of hitting a hard AssertionError when setting an attribute on an untracked user-defined object. ([#196865](https://github.com/pytorch/pytorch/pull/196865), @aperson30)
- AOT compiled-module dispatch now tolerates a guard tree that raises, serving another matching result and quoting the raise in the no-match report. ([#196826](https://github.com/pytorch/pytorch/pull/196826), @bobrenjc93)
- AOT module dispatch now logs a once-per-defect warning when it serves a graph despite another guard tree raising. ([#197391](https://github.com/pytorch/pytorch/pull/197391), @bobrenjc93)
- `torch.cuda.synchronize()` without an index now keeps the index unset under `compile_on_one_rank`, so one artifact serves every rank. ([#196937](https://github.com/pytorch/pytorch/pull/196937), @aorenste)
- Dynamo can now trace `math.ceil`, `math.floor` and `math.trunc` on user-defined objects instead of graph breaking. ([#196867](https://github.com/pytorch/pytorch/pull/196867), @christianaurichzm)
- AOTAutograd now emits all generated runtime-wrapper sources as labeled sections in one `aot_autograd_runtime_wrappers` trace artifact. ([#196129](https://github.com/pytorch/pytorch/pull/196129), @bobrenjc93)

- CPU Flash Attention now overlaps AMX matrix multiplies with AVX softmax, giving roughly 6-29% speedups on some BF16 shapes. ([#191780](https://github.com/pytorch/pytorch/pull/191780), @cfgfung)
